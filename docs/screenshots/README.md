# LendLoop README Screenshots

These are supplied desktop captures of the running LendLoop application. They are suitable as visual references for README preparation; they were provided from an authenticated browser session and were not generated by recreating the UI.

| File | Route | Demonstrates |
| --- | --- | --- |
| `browse-items.png` | `/items` | Search, category filtering, shared listings, images, ratings, and request actions |
| `item-details.png` | `/items/[id]` | Item information, availability, reviews, image, and request action |
| `dashboard.png` | `/dashboard` | Owned items and owner management actions |
| `borrowing-workflow.png` | `/dashboard` | Pending incoming requests with Approve and Decline actions |
| `notifications.png` | `/notifications` | Notification list and read controls |
| `saved-items.png` | `/items/saved` | Saved item cards and request actions |

The dashboard and borrowing workflow captures are separate views because the dashboard content extends below the initial viewport. `LendLoop-README-Screenshots.pdf` contains the four requested primary sections.
